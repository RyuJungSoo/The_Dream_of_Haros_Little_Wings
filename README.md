# 꿈꾸는 작은 날개, 하로

## 게임 개요

| **게임 제목** | 꿈꾸는 작은 날개, 하로 |
| --- | --- |
| **장르** | 2D, 육성 시뮬레이션, 러닝 액션 |
| **플레이어 수** | 1인 |
| **시점** | 횡스크롤 사이드뷰 |
| **플랫폼** | PC (유니티 2D) |

**[시놉시스]**
**“하늘을 향한 가장 작은 날갯짓, 날지 못하는 하로의 첫 비상을 도와주세요.”**

**테라 숲**에서 살아가는 날다람쥐 종족인 **하로**네 가족.

**다른 형제들과 다르게 비행에 소질이 없는** 막내 하로, 하로가 성공적으로 비행을 할 수 있도록 도와주자.

---

## 게임 룰

<img width="1114" height="230" alt="Image" src="https://github.com/user-attachments/assets/083666d1-9c17-44f0-a37a-42115e6102b4" />

**정해진 턴 수** 안에 훈련을 통해 스태미나와 비상력, 균형감 등의 **스탯을 성장**시켜 이를 활용해 최종 비행 구간에서 **목적지까지 도달**해야 한다.

### 육성 스테이지

<img width="1044" height="589" alt="Image" src="https://github.com/user-attachments/assets/4a8522f5-4804-41ab-8be1-b10ab1f3bb20" />

- **마우스**를 사용하여 조작, 훈련 중에 **마우스 왼쪽 버튼**을 **누르고 있으면** 훈련 스킵 가능

각 턴에는 **오직 한 번만** 행동 가능

1. 한 가지 훈련을 선택해서 스탯 성장시키기
2. 휴식으로 체력 회복

**체력이 낮을수록 훈련 실패 확률 증가**

| **스태미나** | 스태미나 최댓값 증가 |
| --- | --- |
| **비상력** | 비행 상승 속도 증가 |
| **균형감** | 스태미나 감소 속도 Down |
| **민첩성** | 장애물 충돌 시 회피 이벤트(QTE) 발생 확률 증가 |

### 비행 시험 스테이지

<img width="990" height="557" alt="Image" src="https://github.com/user-attachments/assets/0628ff62-a292-4933-a3a9-3580277c6746" />

- **스페이스바**와 **키보드**(QTE 한정, WASD, 방향키)를 이용해 하로를 조작
- 스페이스바의 입력에 따라 **상승** or **하강
[스페이스바를 누르고 있으면]** : 상승, 감속, 스태미나 감소 속도 증가
**[스페이스바를 떼면]** : 하강, 가속

- 비행 중에는 **스태미나가 천천히 감소**
- **장애물 충돌 시 스태미나가 크게 감소**
- **스태미나 게이지가 0이 되거나 목표 도달 전에 추락 시 게임 오버**
- 게임 오버 시, **비행 시험 재도전** 혹은 **포기** 가능

### 장애물

- **장애물 충돌 시 스태미나 크게 감소**
- 장애물에는 **벽 타입**과 **낙하물 타입**으로 나뉨
    - **벽 타입** : 고정된 장애물
        
        <img width="776" height="254" alt="Image" src="https://github.com/user-attachments/assets/9f45b264-9729-42bc-848a-f8d62b31a03a" />
        
    - **낙하물 타입** : 움직이는 장애물, **충돌 시 민첩성 판정을 통과하면 회피 이벤트(QTE)**를 통해 회피 가능

### 아이템

- 모든 아이템은 닿는 즉시 **자동 사용**

<img width="810" height="142" alt="Image" src="https://github.com/user-attachments/assets/be5392e1-767c-4d82-9af7-1adfc3504f43" />

- **도토리** : 최대 스태미나의 25%만큼 회복
- **빨간 방울** : 일회용 보호막 생성
- **바람** : 자동 상승, 상승이 끝나기 전까지는 조작 불가능

## 조작키

**대화창**

- 스페이스바 : 스킵

**육성 스테이지**

- 기본 조작은 **마우스**
- **마우스**를 사용하여 조작, 훈련 중에 **마우스 왼쪽 버튼**을 **누르고 있으면** 훈련 스킵 가능

**비행 시험 스테이지**

- **스페이스바** : 비행
- **WASD, 방향키** : QTE 이벤트 조작
- **ESC** : 설정창 열기
